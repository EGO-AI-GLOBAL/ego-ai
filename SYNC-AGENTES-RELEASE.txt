REGRA — DOIS AGENTES, UMA SUBIDA (OBRIGATÓRIO)
================================================

Sempre que QUALQUER agente ou o utilizador pedir build/loja/TestFlight/Play:

  NÃO subir sozinho. Esperar o outro agente. Um build só para todos.

FLUXO (copiar para o outro chat)
--------------------------------

1. ESPERAR — código fundido no Git
   git pull origin main
   (cada agente: commit + push do que fez)
   python scripts/wait_and_submit_eas.py sync-check
   → Só continuar se passar (sem diff pendente app/ + ego_api/)

2. GERAR uma vez (iOS + Android JUNTOS)
   GERAR-E-SUBMETER-JUNTO.bat
   → Grava builds-VERSAO.ids.json (ex: builds-1.0.42.ids.json)

3. SUBMETER uma vez (depois FINISHED nos dois)
   AGUARDAR-E-SUBMETER.bat
   → TestFlight + Play no mesmo fluxo
