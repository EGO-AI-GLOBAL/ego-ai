TU FAZES — PASSO A PASSO (manual)
--------------------------------

PASSO 1 — Redeploy API (freemium na Railway)
1. Abre Railway → serviço ego-ai API
2. Deploy / Redeploy do branch main (depois do push deste código)
3. Confirma: GET https://ego-ai-production-a2c2.up.railway.app/api/health → ok
4. Com conta Essential pós-trial, o access deve ter:
   "show_ads": true
   "access_status": "Essencial (texto + anúncios)"
   "access_allowed": true

PASSO 2 — Conta Google AdMob
1. https://admob.google.com → entra com o e-mail da empresa
2. Apps → Adicionar app → Android (com.egoai.app) + iOS (com.egoai.app)
3. Copia App ID Android e App ID iOS (ca-app-pub-…~…)
4. Em cada app: Blocos de anúncios → Banner → cria 1 banner
5. Copia Unit ID Android e Unit ID iOS (ca-app-pub-…/…)

PASSO 3 — Colar IDs no EAS (produção)
Expo → projeto ego-ai → Environment variables → production:

EXPO_PUBLIC_ADMOB_ANDROID_APP_ID=… (App ID Android)
EXPO_PUBLIC_ADMOB_IOS_APP_ID=… (App ID iOS)
EXPO_PUBLIC_ADMOB_ANDROID_BANNER_ID=… (Banner Android)
EXPO_PUBLIC_ADMOB_IOS_BANNER_ID=… (Banner iOS)

(Ou diz-me os 4 IDs e eu meto no eas.json / config por ti.)

PASSO 4 — Build lojas (depois dos IDs reais)
1. Diz neste chat: "gera 1.0.104 android e ios"
2. Android: upload AAB em Produção Play
3. iOS: TestFlight automático → Distribuição App Store

PASSO 5 — Verificar
- Conta grátis: banner acima do microfone
- Conta Premium: sem banner
- Voz no freemium pós-trial: mensagem a pedir Premium
- Texto freemium: até 10/dia
