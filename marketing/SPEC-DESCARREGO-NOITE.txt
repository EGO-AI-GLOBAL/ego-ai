SPEC — Descarrego da Noite (Night Dump) — MVP 1.0.25
====================================================

OBJETIVO
  35–55 anos: desabafar à noite → amanhã confirmar compromissos em 1 toque.
  IA NÃO grava agenda sem confirmação.

FLUXO
-----
21h  Push → abre «Descarrego» ou chat com mic destacado
     Usuário grava áudio (max 3 min)
     POST /api/v1/night-dump { audio } ou via chat com flag night_dump=1

API
---
1. transcribe_voice_audio (já existe)
2. Gemini prompt estruturado → JSON:
   {
     "comfort_reply": "2-3 frases acolhedoras",
     "reminders": [
       { "title": "Ir ao mercado", "scheduled_at": "ISO tomorrow 18:00",
         "shopping_items": ["Leite", "Sabão em pó"] }
     ],
     "shopping_orphan": [
       { "title": "Dipirona", "category": "remedio" }
     ]
   }
3. INSERT agenda_drafts (user_id, payload, created_at, expires_at +48h)
4. INSERT shopping_drafts ou direto shopping_list se user confirmar só compras

APP MANHÃ
---------
• GET /api/v1/agenda-drafts/pending
• Tela Agenda: banner/card no topo
• Por item: Confirmar | Editar (data/hora/título) | Ignorar
• Confirmar → createReminder + shopping_list_items ligados ao reminder_id
• Itens órfãos (só «comprar X» sem mercado) → lista geral no topo da Agenda

NOTIFICAÇÃO 21h (exemplo)
  Título: Hora de descansar a mente
  Corpo: {Amara}: grave um áudio e solte o que tem para amanhã. Eu organizo — você dorme.

AVATARES SUGERIDOS
  Omar, Amara, Luna (calmos)

BANCO (Supabase)
----------------
create table agenda_drafts (
  id uuid primary key default gen_random_uuid(),
  user_id uuid not null references auth.users(id) on delete cascade,
  source text not null default 'night_dump',
  comfort_reply text,
  items jsonb not null default '[]',
  created_at timestamptz not null default now(),
  expires_at timestamptz
);
-- items: [{ type: 'reminder'|'shopping', title, scheduled_at?, category? }]

RLS: user_id = auth.uid()

LIMITES PLANO
-------------
grátis: 3 descarregos/semana
premium+: ilimitado

NÃO FAZER NO MVP
----------------
• Gravar automaticamente sem confirmar
• Agenda compartilhada via descarrego (só pessoal v1)
