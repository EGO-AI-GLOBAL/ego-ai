PASSO A PASSO
-------------

1) Build 46 visivel em TestFlight > Builds iOS
   Status: "Pronto para envio" ou "Processando"

2) Export compliance (se pedir no build 46)
   "Seu app usa criptografia?" → NAO (so HTTPS padrao)

3) Testes EXTERNOS (nao confundir com Internos)
   Menu: TestFlight > Testes externos
   Abra o grupo (ex: "Testadores EGO")

4) Adicionar build ao grupo externo
   Grupo > Builds > + > versao 1.0.59 / build 46
   Cole o texto "O QUE TESTAR" abaixo

5) Enviar para revisao beta
   "Enviar para revisao" / "Submit for Review"
   Apple: algumas horas ate 1-2 dias

6) Status = "Pronto para testar" / "Testing"
   Avise o grupo (MENSAGEM-TESTADORES-1.0.59.txt)
