# Prompt para imagem do site EGO-AI

Use no **ChatGPT (DALL·E)**, **Midjourney**, **Leonardo**, **Ideogram** ou similar.  
Depois salve como **`marketing/landing/img/hero-banner.png`** (recomendado **1840×1035 px** ou 16:9).

---

## Prompt principal (copiar e colar)

```
Wide hero banner for a mobile app landing page, Brazilian Portuguese product "EGO-AI".
Dark elegant UI background (#09090B charcoal black), soft purple accent glow (#A78BFA, #7C3AED).
Two friendly AI companion characters side by side: "Luna" (young woman, warm smile, soft lighting, approachable)
and "Leo" (young man, calm confident expression). Semi-realistic digital portrait style, not cartoon,
not anime. Subtle holographic or glass UI elements, smartphone silhouette showing chat and voice waves.
Mood: human connection, warmth, late evening cozy light — NOT corporate, NOT robot factory.
Text-free image, no logos, no watermarks, no letters, no UI mockup text.
Professional app store marketing quality, 16:9 composition, center-weighted for web crop,
high detail, cinematic soft bokeh background.
```

## O que evitar na imagem

- Texto ou logo na imagem (a gente coloca no HTML)
- Robô metálico estilo industrial
- Visual “empresa B2B” frio
- Muitos elementos poluídos

## Depois de gerar

1. Salve o arquivo: `marketing/landing/img/hero-banner.png`
2. Rode: `python scripts/build_site_publico.py` (ou `python scripts/zip_site_publico.py`)
3. Me envie a imagem no chat — eu confirmo se ficou boa no layout

A imagem aparece automaticamente no topo da página quando o ficheiro existir.
