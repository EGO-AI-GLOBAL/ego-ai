════════════════════════════════════════

PASSO A — Conta de serviço Google (para ler compras)
----------------------------------------------------
1. Google Play Console → Configurações → **Acesso à API** (API access)
2. Liga a um projeto Google Cloud (cria se pedir)
3. Cria **Conta de serviço** (Service account) no Google Cloud
4. Dá o papel/permissão para ver compras financeiras
5. Volta à Play Console → concede acesso a essa conta de serviço:
   permissão **Ver dados financeiros / Gerir pedidos e assinaturas**
6. No Google Cloud → a conta de serviço → **Chaves** → Criar chave **JSON**
   → guarda o ficheiro .json

PASSO B — Colar no Railway (serviço da API EGO-AI)
--------------------------------------------------
Railway → projeto EGO-AI (API) → Variables → New variable:

  GOOGLE_PLAY_SERVICE_ACCOUNT_JSON
    = (cola TODO o conteúdo do .json numa linha)

  GOOGLE_PLAY_PACKAGE_NAME
    = com.egoai.app

(Alternativa ao JSON inline: GOOGLE_PLAY_SERVICE_ACCOUNT_FILE = caminho do .json)

Depois: Railway faz redeploy sozinho. Confirmar /api/health sem maintenance.
