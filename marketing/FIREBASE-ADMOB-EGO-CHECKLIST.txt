EGO-AI — Firebase Analytics + AdMob interstitial/rewarded
=========================================================
Data: 2026-08-15 · NÃO buildar até «pode buildar»


1) FIREBASE (project EGO — NÃO ShapeScan)
----------------------------------------
1. console.firebase.google.com → criar / abrir project **EGO-AI**
2. Add app Android: package com.egoai.app → descarrega google-services.json
3. Add app iOS: bundle com.egoai.app → descarrega GoogleService-Info.plist
4. Cola os ficheiros em:
     app/google-services.json
     app/GoogleService-Info.plist
5. Activa Analytics (GA4) no project
6. app.config.ts liga o plugin só se estes ficheiros existirem


2) EVENTOS (código já dispara)
------------------------------
  first_open                      — 1× por instalação
  login / sign_up                 — AuthContext
  session_or_checkin_completed    — check-in Monstrinhos (1º do dia) + PAUSA
  paywall_view                    — ecrã Planos (focus)
  trial_start                     — ao iniciar IAP / abrir Stripe
  purchase / subscribe            — IAP sucesso; Stripe checkout aberto
  interstitial_ad / rewarded_ad   — diagnóstico ads

Banner já existe (banner-chat-free). Ver ADMOB-IDS-EGO-AI.txt.
