SYNC AGENTES — 1.0.111 (mestre)
================================
Versão: 1.0.111 · iOS buildNumber 116 · Android versionCode 169

MOTIVO
------
Bug diário: abrir o app → Monstrinhos/Agenda/Calma sem sync → só
logout+login recuperava. Inadmissível.

CAUSA RAIZ
----------
require_auth renovava o access com X-Refresh-Token no servidor e NÃO
devolvia o refresh novo ao app. O telemóvel ficava com refresh já usado
(morto). Pull-to-refresh reusava o mesmo token morto. Logout+login
gerava tokens novos.

CORREÇÃO
--------
API (flask_api.py + services.py):
  - Ecoa X-EGO-Access-Token / X-EGO-Refresh-Token / X-EGO-Expires-At
    quando require_auth rota a sessão
  - CORS expose_headers desses campos
  - format_auth_error: "already used" / invalid refresh →
    "Sessão expirada. Entre de novo." (401 hard, não soft 503)

App (client.ts + AuthContext.tsx):
  - Interceptor de sucesso grava tokens ecoados
  - Renova proactivamente ANTES do pedido se access a expirar
  - Refresh morto limpa sessão (em vez de soft-lock eterno)
  - refreshSessionToken propaga mensagem real da API

api_build = 2026-08-11-auth-echo-refresh-tokens
