PASSO A PASSO
-------------
1. Abra: https://supabase.com/dashboard
2. Entre no projeto EGO-AI
3. Menu esquerdo: Authentication
4. Submenu: URL Configuration
5. Secção: Redirect URLs
6. Clique em "Add URL" (ou "+") e cole CADA linha abaixo (uma de cada vez):

   https://ego-ai-production-a2c2.up.railway.app/auth/reset-password

   egoai://reset-password

7. Clique Save

Site URL (pode ficar como está ou usar):
   https://ego-ai-production-a2c2.up.railway.app

Sem isto o e-mail «Esqueci a senha» não abre a página certa.
